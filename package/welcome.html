This installer contains packages for srcDiff, a syntactic differencing tool built on top of srcML. It can:

  • Compute differences between two versions of a source file (or directories)
  • Produce a srcDiff document (marked up srcML), from which both the original and modified source can be recovered
  • View differences as a colorized, unified, or side-by-side diff output either on the terminal or as an HTML document

By default, the srcdiff command-line client is installed. You can also install the libsrcdiff development package which lets you use srcDiff in your own application.

For further details, visit srcDiff.org
