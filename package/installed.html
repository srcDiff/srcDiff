For details on the srcdiff command-line program, run srcdiff --help. Here's some examples of how to use it:


# Compute the srcDiff of two versions of a file
srcdiff original.cpp modified.cpp -o diff.cpp.xml

# Compare two directories
srcdiff original_dir modified_dir -o project.xml

# Show a colorized unified diff
srcdiff -u original.cpp modified.cpp

# Show the whole file instead of just the context around changes
srcdiff -u -C all original.cpp modified.cpp

# Show a colorized side-by-side diff (argument is the tab size)
srcdiff -y 2 original.cpp modified.cpp

# Save the unified view as an HTML page
srcdiff --html -u original.cpp modified.cpp -o diff.html

If you installed the libsrcdiff development package, you can write applications that use libsrcdiff directly. It contains the following:

  • The include file srcdiff.h
  • The shared and static libsrcdiff libraries
  • The libsrcdiff API documentation (HTML)
